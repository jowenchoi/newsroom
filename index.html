  1. GitHub 토큰 만들기 (Fine-grained token)
  2. Repository access: Only select repositories → newsroom
  3. Permissions → Repository → Actions: Read and write (나머지는 그대로)
  4. 만든 토큰(github_pat_…)을 아래에 붙여넣기

토큰은 이 기기의 이 브라우저에만 저장되고 다른 곳으로 보내지지 않습니다 (GitHub API 호출에만 사용). 토큰 없이 하려면 GitHub에서 직접 실행하세요.
